# Task 1: Diagnostic Enhancement of Chest X-Rays

Notebook: `xray_enhancement.ipynb`

Operations: load and display, histogram equalization, COLORMAP_JET, color balance (gray-world), dense-tissue thresholds (190, 220, 245), logarithmic transform, power-law transform (gamma below 1), and a combined pipeline on a second sample.

Inputs: `data/sample_xray.jpg`, `data/sample_xray_2.png`. Results are written to `output/`.
